  <what-built>
All six DnD improvements from plans 03-01 and 03-02:
- DND-02: Drop row highlight (directory rows glow selection-background color during drag)
- DND-06: VFS refresh of source parent directory after drag-move
- DND-04: Ghost drag image (translucent icon + filename follows cursor)
- DND-01: Modifier key COPY/MOVE + drag to IntelliJ project view reliability
- DND-03: Auto-scroll when cursor held near top/bottom edge of tree
- DND-05: Dropping on a file targets parent directory
- Conflict dialog: "Replace existing file?" when filename collision
- Balloon notification: error balloon on I/O failure instead of silent failure
  </what-built>
  <how-to-verify>
In the sandboxed IntelliJ IDE (launched by Task 1):

1. **DND-02 — Drop highlight:**
   Open System Explorer tool window. Drag any file slowly over the tree. Verify: directory rows show a blue/selection-color background as cursor passes over them. File rows should NOT highlight. Highlight should clear immediately when cursor leaves the tree or drop completes.

2. **DND-04 — Ghost image:**
   Start dragging a single file. Verify: a translucent image showing the file's icon + filename follows the cursor. Drag multiple files. Verify: image shows "filename (+N more)" badge. Image should be visibly translucent (not fully opaque).

3. **DND-03 — Auto-scroll:**
   Open a directory with many files so the tree is taller than the visible area. Start dragging a file and hold the cursor at the very top edge of the tree. Verify: tree scrolls upward. Hold at the bottom edge. Verify: tree scrolls downward.

4. **DND-01 — Drag to IntelliJ project view:**
   Drag a file from System Explorer and drop it onto IntelliJ's Project View panel. Verify: the file appears in the project view location without error or silent failure. Test COPY: hold Option (macOS) / Ctrl (Windows/Linux) while dropping. Verify: file is copied, not moved.

5. **DND-05 — Drop on file targets parent:**
   Drag a file and drop it directly onto another file (not a directory). Verify: the dragged file moves into the other file's parent directory (not a nested location or an error).

6. **DND-06 — VFS source refresh:**
   Drag a file from one directory to another (move). Verify: the source directory no longer shows the moved file immediately after the drop (no stale entry).

7. **Conflict dialog:**
   Drag a file into a directory that already contains a file with the same name. Verify: a "Confirm Replace" dialog appears with "Replace" and "Skip" buttons. Click Skip — verify the file is NOT replaced. Repeat and click Replace — verify the file IS replaced.

8. **No regression:**
   Right-click a file and use Copy/Cut/Paste from the context menu. Verify these operations still work normally.
  </how-to-verify>
