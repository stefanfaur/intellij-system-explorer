    In RipgrepContentSearch class body, add a companion object entry or top-level private function:

    ```kotlin
    private val ALLOWED_FLAGS = setOf("--hidden", "--no-ignore", "--follow")
    private val ALLOWED_PREFIXES = setOf("--type", "--glob")

    private fun validateExtraFlags(flags: String): List<String> {
        if (flags.isBlank()) return emptyList()
        return flags.trim().split("\\s+".toRegex()).filter { token ->
            when {
                token.isBlank() -> false
                token in ALLOWED_FLAGS -> true
                ALLOWED_PREFIXES.any { token.startsWith(it) } -> true
                else -> false  // blocks --exec, unknown --, and everything else
            }
        }
    }
    ```

    Then replace the unsafe lines (current lines 76-77):
    ```kotlin
    // REMOVE:
    val extra = s?.ripgrepExtraFlags?.trim() ?: ""
    if (extra.isNotBlank()) cmd.addAll(extra.split("\\s+".toRegex()))

    // REPLACE WITH:
    val extra = s?.ripgrepExtraFlags?.trim() ?: ""
    cmd.addAll(validateExtraFlags(extra))
    ```

    The ALLOWED_FLAGS and ALLOWED_PREFIXES constants and validateExtraFlags function should be placed in the companion object of RipgrepContentSearch (it already has a companion object with LOG and DEFAULT_MAX_CONTENT_RESULTS).

    The validateExtraFlags private method goes in the class body (not companion object) since it uses no static state.
