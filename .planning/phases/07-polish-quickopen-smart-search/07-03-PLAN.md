<objective>
Implement the UI polish pass: add the ranker/root/file-count status bar with clickable root picker, change speed dial to pure frecency, condense the hint bar to 5 essential shortcuts, add match character highlighting in the parent path segment of result rows, and implement result-type grouping order (Recent/bookmarks first → files → directories) in the ranking pipeline.

Purpose: These are the visible UX improvements that make the Quick Open popup feel polished and transparent. The status bar tells users which ranker is active and what they are searching. Speed dial should reflect actual recent usage. The hint bar should not overwhelm users with rarely-used shortcuts. Path segment highlighting aids result scanning. Result grouping ensures high-signal results (bookmarks, recent) surface above raw filesystem matches.

Note on QO-RANK-01: The frecency boost component (balanced blend of fuzzy score + frecency + proximity) is ALREADY IMPLEMENTED in Ranker.kt (text×0.50 + frecency×0.32 + prox×0.08 + boosts×0.10). This plan implements the result-type grouping order, which is the missing piece of QO-RANK-01.
