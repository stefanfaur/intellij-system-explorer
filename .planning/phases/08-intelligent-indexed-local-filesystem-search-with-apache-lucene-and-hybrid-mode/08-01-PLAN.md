  <action>
Create `LuceneIndexManager.kt` in package `ro.faur.explorer.quickopen.index`.

Use `ByteBuffersDirectory` in tests (RAMDirectory was removed in Lucene 9). For production use `NIOFSDirectory(indexPath)` — NOT `FSDirectory.open()` which auto-selects MMapDirectory (causes file handle leaks on plugin unload).

Analyzer: `PerFieldAnalyzerWrapper` with `WhitespaceAnalyzer` for FIELD_PATH and FIELD_FILENAME, `StandardAnalyzer` for FIELD_CONTENT. This handles camelCase tokenization for code paths correctly.

IndexWriter config: `OpenMode.CREATE_OR_APPEND`. Wrap in a try/catch for `IndexFormatTooOldException` and `CorruptIndexException` — on either, delete the index directory recursively and recreate with `OpenMode.CREATE`. Log the rebuild with `LOG.warn`.

For `searchPaths`: use `WildcardQuery` on FIELD_FILENAME (primary) and FIELD_PATH (secondary) joined with `BooleanClause.Occur.SHOULD`. Always lowercase the query before building the wildcards. Use `DirectoryReader.open(directory)` after `writer.commit()`.

For `searchContent`: use `QueryParser(FIELD_CONTENT, analyzer).parse(QueryParser.escape(pattern))`. Use `UnifiedHighlighter` for snippets. Check the package — in Lucene 9.12.3, UnifiedHighlighter is in `org.apache.lucene.search.uhighlight`. If the import fails, add `lucene-highlighter:9.12.3` as an additional dependency.

`indexDirForRoot`: hash the rootPath string with SHA-256 (`MessageDigest.getInstance("SHA-256")`), take the first 16 hex chars, return `Paths.get(PathManager.getSystemPath(), "caches", "explorer-index", hash)`. Use `PathManager.getSystemPath()` (not `getPluginTempPath()` which is cleared on restart) so the index survives IDE restarts.

`numDocs()`: commit then open a DirectoryReader and return `reader.numDocs()`.

The class implements `Closeable`. `close()` closes writer, directory, and analyzer in that order, catching and logging exceptions.

Test file uses `ByteBuffersDirectory` to avoid disk I/O. Instantiate a test manager by passing a constructor that accepts a `Directory` directly (add a package-private secondary constructor for tests), or use a temp directory via `Files.createTempDirectory`.
