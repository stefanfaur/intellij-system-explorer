  <action>
    Create `CompareWithAction.kt` in package `ro.faur.explorer.actions`.

    The action:
    - `getActionUpdateThread()` returns `ActionUpdateThread.BGT`
    - `update(e)`: enabled and visible only when `tree != null && isExplorerActive(e) && tree.getSelectedFiles().size == 2`
    - `actionPerformed(e)`:
        1. Get the two selected files: `val selected = tree.getSelectedFiles()` — guaranteed size == 2 by update()
        2. Look up VirtualFiles:
           ```kotlin
           val leftVf = LocalFileSystem.getInstance().findFileByPath(selected[0].path) ?: return
           val rightVf = LocalFileSystem.getInstance().findFileByPath(selected[1].path) ?: return
           leftVf.refresh(false, false)
           rightVf.refresh(false, false)
           ```
        3. Build DiffContent for each:
           ```kotlin
           val factory = DiffContentFactory.getInstance()
           val leftContent = factory.create(project, leftVf)
           val rightContent = factory.create(project, rightVf)
           ```
        4. Build request:
           ```kotlin
           val request = SimpleDiffRequest(
               "Compare: ${selected[0].name} vs ${selected[1].name}",
               leftContent, rightContent,
               selected[0].name, selected[1].name
           )
           ```
        5. Show diff on EDT (actionPerformed is already on EDT for actions):
           ```kotlin
           DiffManager.getInstance().showDiff(project, request, DiffDialogHints.FRAME)
           ```

    Note: `selected[0]` = first file by tree row order (top) = left side, `selected[1]` = second = right side. This is the documented behavior from RESEARCH.md Pitfall 5 — use tree order, not click order.

    Required imports:
    ```kotlin
    import com.intellij.diff.DiffContentFactory
    import com.intellij.diff.DiffDialogHints
    import com.intellij.diff.DiffManager
    import com.intellij.diff.requests.SimpleDiffRequest
    import com.intellij.openapi.actionSystem.ActionUpdateThread
    import com.intellij.openapi.actionSystem.AnAction
    import com.intellij.openapi.actionSystem.AnActionEvent
    import com.intellij.openapi.vfs.LocalFileSystem
    import ro.faur.explorer.actions.ExplorerActionUtil
    ```

    ANTI-PATTERNS to avoid:
    - Do NOT use the old `com.intellij.openapi.diff.*` package — use `com.intellij.diff.*` exclusively (STATE.md locked decision)
    - Do NOT call showDiff() on a background thread — actionPerformed fires on EDT, which is correct
    - Do NOT skip the `vf.refresh(false, false)` call — avoids stale VFS content (RESEARCH.md Pitfall 4)
  </action>
